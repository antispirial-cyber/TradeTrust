TRADETRUST — DESIGN
===================

THE FEELING
-----------
TradeTrust is used by traders who stand in markets all day in bright sunlight,
checking their phones between deals. The UI needs to be dark, high contrast,
and dense without feeling cluttered. Not a startup landing page. Not social
media. Think: a professional directory that means business.

One visual rule above everything else: the score ring is the star.
Every other visual decision exists to support it. Keep the rest quiet.

Users can pick their own accent color in settings. The global chrome is
always neutral dark. The accent is personal to each user.


TOKENS — put all of these in variables.css
------------------------------------------
These are the only values that should ever appear in CSS files.
Anything marked TEAM DECISION needs to be filled in before coding starts.

Colors:
  --bg-primary        TEAM DECISION  (deep dark background, suggest #0F1117 or #1A1D2E)
  --bg-secondary      TEAM DECISION  (slightly lighter, for sidebar and navbar)
  --bg-card           TEAM DECISION  (card surface, just above bg-secondary)
  --bg-input          TEAM DECISION  (input field fill)
  --border-color      TEAM DECISION  (subtle 1px dividers)
  --text-primary      TEAM DECISION  (near-white main text)
  --text-secondary    TEAM DECISION  (muted text, labels, metadata)
  --text-placeholder  TEAM DECISION  (input placeholder)

  --accent-color      #4A90E2        (default, replaced at runtime by user setting)
  --accent-hover      (10% lighter than accent)
  --accent-muted      (accent at 20% opacity, for active sidebar backgrounds)

Score ring gradient stops (do not change these):
  score 0.0  = #D62828  deep red
  score 2.5  = #F77F00  orange
  score 5.0  = #F4D35E  amber
  score 7.5  = #90BE6D  lime
  score 10.0 = #2DC653  vivid green
  Interpolate linearly between stops based on exact score value.

Status colors:
  --status-pending  #F4D35E
  --status-success  #2DC653
  --status-danger   #D62828
  --status-neutral  #8B8FA8

Verified badge: #2DC653 background at 15% opacity with a checkmark icon.

Typography:
  --font-primary  TEAM DECISION  (suggest IBM Plex Sans — clean, professional)
  --font-mono     TEAM DECISION  (suggest IBM Plex Mono — for scores and amounts)

Type scale:
  --text-xs    11px  (timestamps, metadata)
  --text-sm    13px  (labels, table rows)
  --text-base  15px  (body, form inputs)
  --text-md    18px  (card titles, section headings)
  --text-lg    24px  (page headings)
  --text-xl    32px  (score number inside ring)

Spacing:
  --space-xs   4px
  --space-sm   8px
  --space-md   16px
  --space-lg   24px
  --space-xl   40px

Layout:
  --sidebar-width      240px
  --navbar-height      56px
  --card-radius        10px
  --input-radius       6px
  --max-content-width  1100px

Shadows:
  --shadow-card   0 2px 8px rgba(0,0,0,0.25)
  --shadow-modal  0 8px 32px rgba(0,0,0,0.45)

Transitions:
  --transition-fast  150ms ease
  --transition-base  250ms ease


LAYOUT
------
After login, every page uses this shell:

  Sidebar (240px, left, full height, bg-secondary)
    Logo image at top (logo.png from /public, not text)
    Nav links with icons below it
    User avatar and name at very bottom, with logout

  Navbar (56px, top, full width minus sidebar, bg-secondary)
    Search bar center-left (desktop only)
    Bell icon right (with unread count badge)
    User avatar right

  Content area (remaining space, scrollable, max-width 1100px centered)

Mobile (under 768px):
  Sidebar hidden. Bottom navigation bar with icons instead.
  Navbar shows logo + bell + avatar only.
  Content full width with smaller padding.

Sidebar active link: 3px left border in --accent-color, background in
--accent-muted. Transition on all state changes: --transition-fast.


COMPONENTS
----------

SCORE RING
  SVG circle, not filled, stroke only.
  Stroke color = interpolated gradient color for this score.
  Stroke fill level proportional to score (full circle at 10, empty at 0).
  Glow: drop-shadow in same color at 40% opacity. Do not skip the glow.
  Center: score number in --font-mono --text-xl. Below: "/ 10" in --text-xs.
  Sizes:
    Large  (profile page)   120px diameter, 8px stroke
    Medium (dashboard)       90px diameter, 7px stroke
    Small  (browse card)     48px diameter, 5px stroke
  During score freeze: ring shows last value. No visual change publicly.

TRADER CARD  (browse grid)
  ~280px wide. Grid: 3-4 columns desktop, 1-2 mobile.
  Shop thumbnail photo: full card width, 140px tall, object-fit cover.
  Small score ring: bottom-right corner of photo, slightly overlapping.
  Verified badge: top-left corner of photo if earned.
  Below photo:
    Business name (--text-md, 600 weight)
    Role + Sector (--text-sm, --text-secondary)
    Cluster (--text-xs, --text-secondary)
    Business description (2 lines max, ellipsis overflow)
    Mutual connection count if any (--text-xs, --accent-color)
    Connect button (full width, --accent-color)
  Card border: 1px --border-color. Radius: --card-radius.
  Hover: shadow lifts slightly. Click anywhere except button: go to profile.

SIDEBAR
  Logo at top (img tag, /logo.png, not text).
  Nav links: icon + label, 44px each, full width.
  Active: --accent-color left border 3px + --accent-muted background.
  Bottom: small user avatar + name + logout link.

NAVBAR
  Search bar (desktop): 360px, placeholder "Search traders by name or phone..."
  Bell icon: red badge top-right if unread count > 0.
  Avatar: circle with user initials if no photo.

CONNECT BUTTON STATES
  Not connected: filled, --accent-color, "Connect"
  Request sent:  outlined, --text-secondary, "Pending", disabled
  Connected:     outlined, --status-success, "Connected", no click action
  Request received: two small buttons, "Accept" and "Decline"

COMPLAINT MODAL
  Full overlay. 3-step progress indicator at top.
  Step 1: description textarea, amount field, date picker (defaults today).
  Step 2: file upload drag-drop area. Show filename after selection.
  Step 3: summary of what will be submitted. Submit button.
  Cancel always visible. After submit: replace with confirmation message.

LEDGER TABLE
  Columns: Date | Party | Type | Amount | Status | Notes | Actions
  Amount: --font-mono, right-aligned.
  Status: small pill badge using status colors.
  Running balance above table:
    "Outstanding Credit Given: ₹X,XX,XXX"
    "Outstanding Credit Received: ₹X,XX,XXX"
    Both in --font-mono --text-md.

NOTIFICATION ITEM
  Icon left (type-specific). Message text. Timestamp (relative: "2h ago").
  Unread: --accent-muted background. Read: normal --bg-card.
  Click: navigate to link_ref.

VERIFIED BADGE
  Small pill. Green checkmark + "Verified" in --text-xs.
  Shows on profile header and top-left of trader card.

REPORT BUTTON
  Flag icon. --text-secondary normally. --status-danger on hover.
  Tooltip on hover: "Report this trader". Click: opens ComplaintModal.


PAGES IN DETAIL
---------------

LOGIN PAGE  /login
  No sidebar. No navbar. Full screen.
  Centered card 480px wide (--bg-card, --shadow-modal).
  Logo at top of card.
  Tagline below logo: "Know who you're trading with."
  Two tabs: Login | Register.
  Login: phone + password + button.
  Register: name, phone, business name, description, role toggle,
            cluster dropdown, sector dropdown, password + button.
  Small link at bottom: "Admin access" → /admin/login.

DASHBOARD  /dashboard
  Profile header: shop photo (80px circle), name, role, cluster.
  Score ring (medium) far right of header.
  Verified badge below name if earned.
  Tab bar below header: Profile | Ledger | Past Records.
  Past Records tab is hidden until user clicks the score ring.
  After first click it stays visible.

BROWSE  /browse
  Search bar full width at top.
  Filter row: Cluster dropdown | Sector dropdown | Role toggle.
  Result count line: "Showing X traders in [Cluster]"
  Card grid below. Pagination if results > 20.
  Empty state: centered message + simple illustration.

PUBLIC PROFILE  /profile/:id
  Same header layout as dashboard but read-only.
  Action buttons: Connect | Report (flag icon).
  Tabs: About | Past Records.
  About: full description, sector, cluster, connection count.
  Past Records: approved complaints only. If none: "No verified records on file."

NOTIFICATIONS  /notifications
  List newest first. Mark all as read button top right.
  Group by date if more than 10 items: Today / This Week / Earlier.

SETTINGS  /settings
  Two sections clearly separated.
  Account Details: all editable fields, Save button.
  Appearance: 8 color swatches (circles, 32px each) + custom hex input.
  Live preview: small sample element showing accent color applied.
  Save Appearance button.

ADMIN PANEL  /admin
  No trader sidebar. Simple top bar: "TradeTrust Admin" + logout.
  Two columns: complaint list left (scrollable), thread detail right.
  Complaint list item: reporter → reported, date, status pill.
  Thread view: full conversation, proof images rendered inline.
  Approve (green) and Reject (red) buttons with confirmation dialog.
  Broadcast form at bottom.


MOTION RULES
------------
Keep motion minimal. One rule: motion answers actions, it does not decorate.

Allowed:
  Score ring color change: animate from old to new color over 800ms.
  This is the ONE signature animation. Make it good.
  Modal open: fade in + scale 95% to 100%, --transition-base.
  Tab indicator: slides left-right, --transition-fast.
  Sidebar active state: --transition-fast on background and border.
  Button hover: --transition-fast on color.
  Card hover: --transition-fast on shadow.

Not allowed:
  Page load animations on sections.
  Scroll-triggered reveals.
  Staggered card entrances.
  Anything that plays without user action (except score ring color change).


RESPONSIVE
----------
Mobile   < 768px   sidebar hidden, bottom nav, single column cards
Tablet   768-1024  sidebar hidden, 2-column card grid
Desktop  > 1024    sidebar visible, 3-4 column card grid
